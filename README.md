📝 To-Do List App

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript. It helps users organize their daily tasks, track completed activities, and manage pending tasks efficiently.

🚀 Features

- ➕ Add new tasks dynamically.
- ✅ Mark tasks as completed or active.
- 📋 View all tasks.
- 🔄 Filter tasks by All, Active, and Completed.
- ❌ Delete individual tasks.
- 🧹 Clear all completed tasks.
- 🎨 Dynamic UI updates using JavaScript DOM manipulation.
- 📱 Simple and user-friendly interface.

🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript (ES6) – DOM manipulation and event handling.
